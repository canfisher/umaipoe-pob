우마이 한글 PoB r12 — 도구 한국어·3.30 주얼·실행 전 업데이트

변경 내용
- 홈과 도구의 한국어 표기를 확장했습니다. 아틀라스·필터·게임 검색식·보관함 기록·주얼 검색의 하위 메뉴를 함께 정리했습니다.
- 이전 언어 설정이 남아 있어도 한국어 자료를 사용하도록 했습니다. 원본 번역 업데이트가 한국어 자료를 덮지 않도록 배포 경로를 통합했습니다.
- 무궁한 주얼은 공식 3.30 패시브 트리(1,999개 노드, 21개 주얼 홈)를 사용합니다. 검색 자료 누락 검사와 한국어 속성·번호 검색을 추가했습니다.
- 주얼 도구의 효과 수치를 이 배포본의 3.30 계산 자료와 맞췄습니다. 데이터 배열 순서와 번호 대응은 유지했습니다.
- 한국어 게임 아이템 복사문을 판독하는 필터 자료와 공식 한국 거래소 속성 자료를 보강했습니다.
- 새 Umaipoe-PoB.exe는 실행할 때 업데이트를 먼저 확인하고 준비된 새 버전을 적용한 후 PoB를 엽니다. 네트워크 오류일 때는 설치된 정상 버전으로 실행합니다.
- 빌드·설정은 별도 사용자 폴더에 보존합니다. 업데이트 실패 시 이전 버전으로 돌아가며, 도구에서 저장한 설정도 이전 설치에서 가져옵니다.

실행 방법
1. 다운로드한 Umaipoe-PoB.exe를 실행합니다. ZIP 압축 해제나 CMD 실행은 필요하지 않습니다.
2. 첫 실행은 프로그램 자료를 내려받으므로 이후 실행보다 오래 걸립니다. 업데이트 중에는 창을 닫지 말아 주세요.
3. 바탕화면의 '우마이 한글 PoB 자동 업데이트'로 실행하세요. 예전 폴더의 pob-zh.exe를 직접 실행하면 새 실행기의 자동 업데이트를 거치지 않습니다.
4. Shift를 누르고 실행하면 관리 메뉴에서 기존 폴더 가져오기와 이전 버전 복구를 사용할 수 있습니다.
5. 무궁한 주얼: 홈 → 무궁한 주얼 → 종류·원하는 속성·트리의 주얼 홈 선택 → 이 홈에서 검색. 결과의 보기로 해당 번호의 변화를 확인합니다.

업데이트 적용 시점
r12 실행기(버전 3)는 매 실행 전 확인합니다. 예전 실행기는 먼저 PoB를 열고 업데이트를 준비하는 방식이므로, 새 실행기로 교체되기 전에는 종료 후 다음 실행에 적용될 수 있습니다. 즉시 동일하게 사용하려면 위 EXE를 새로 내려받아 실행하세요.

확인한 범위와 남은 제한
- 3.30 트리 로딩, 한국어 주얼 속성 검사 3,030개, 3.30 트리 구조 검사, 심연 주얼 검사 48개를 통과했습니다.
- 한국어 셉터·장화·목걸이 실제 게임 복사문 3개를 필터에서 판독하고 조건 일치를 확인했습니다.
- 아틀라스 파밍 자동 배치와 무궁한 주얼 트리는 3.30입니다. 기존 수익 탭의 지도·관측기 배치 모델에는 이전 자료가 남아 있으며, 3.30 수익 검증 완료로 표시하지 않습니다.
- 한국어 원문이 아직 연결되지 않은 일부 세부 카탈로그 이름은 영어로 남습니다. 모든 데이터와 모든 계산을 100% 검증한 공식판이라는 뜻은 아닙니다.
- 게임 서버의 실제 결과·시세·수익을 검증한 자료는 아닙니다. 원본 오픈소스 라이선스 고지는 유지합니다.
